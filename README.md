# watchstat — 视频观看覆盖统计库

进程内内存实现，由上层直接调用。按内容覆盖去重统计观众真正看过的时长，
支持拖动、重复观看、多会话重叠与迟到补报（已展示的统计随之修正，包括撤回）。

## 接口

```go
tr := watchstat.NewTracker(100_000) // 固定视频，时长（毫秒），上限 7200000
tr.Ingest(watchstat.Event{          // play/pause/seek/completion 统一为事件
    ViewerID: "v1", SessionID: "s1", EventID: "e1",
    TimeMs: 0, PosMs: 0, Playing: true,
})
watched := tr.WatchedMs("v1")       // 指定观众去重后的已看时长（毫秒）
sum := tr.Summary()                 // 视频汇总：有效观众数、平均观看比例、
                                    // 25%/50%/75%/100% 四档里程碑人数
```

规则要点：

- 会话内相邻事件对，仅当前一项执行后为播放中时贡献观看区间
  `[位置, 位置+min(时间差, 视频剩余时长))`，起点计入、终点不计入；
  最后一项事件不贡献区间，不按当前时间补算。
- 事件标识在会话内唯一，重复投递自动去重；同会话按
  （发生时刻，事件标识）排序还原，不同会话独立，接收顺序不影响结果。
- 同一观众全部会话共同计算覆盖，重复播放、多会话重叠只计一次。
- 每次 `Ingest` 返回后查询即反映全部已接收事件（增量维护，查询 O(1)）。

## 实现

- `tracker.go`：公开 API 与增量维护的汇总指标。
- `session.go`：会话事件的有序插入与相邻事件对的区间贡献增删。
- `coverage.go`：基于 treap 的区间多重集合（引用计数 + 相邻合并），
  支持区间增删与 O(1) 已覆盖总时长查询。

## 运行测试

```sh
go test ./...            # 全部测试（含性能测试）
go test -short ./...     # 跳过性能测试
go test -run TestPerformance -v .   # 仅性能测试
```

测试内容：

- `tracker_test.go`：验收场景（100 秒视频补报拖动事件后覆盖从 100 秒降为
  20 秒且里程碑归零）、多会话重叠去重、重复投递、拖动跳过、重复播放、
  末尾事件不贡献、里程碑阈值含等号、乱序会话。
- `fuzz_test.go`：乱序随机事件（含重复投递），每次接收后与独立参照实现
  （从完整事件集重算）逐观众与汇总比对。
- `coverage_test.go`：区间集合与逐毫秒位图参照的随机增删比对。
- `perf_test.go`：20 万事件、1 万观众（单人 10 万条）后，再插入 1 万条
  时间线中间事件并逐条查询，要求 < 10 秒、堆内存 < 512 MiB
  （本机实测约 0.9 秒、46 MiB）。
